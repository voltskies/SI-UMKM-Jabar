\begin{abstract}
Sektor Usaha Mikro, Kecil, dan Menengah (UMKM) memegang peranan krusial dalam pertumbuhan ekonomi Jawa Barat. Namun, publikasi data UMKM saat ini masih terfragmentasi dan disajikan dalam format tabular statis, sementara alur pelayanan pengajuan program bantuan, perizinan, dan pelatihan masih berjalan secara terpisah tanpa mekanisme pelacakan yang terpadu. Penelitian ini bertujuan merancang dan mengimplementasikan SI-UMKM Jabar, sebuah platform e-governance terpadu berbasis web yang memadukan visualisasi geografis interaktif dan layanan mandiri pelaku usaha. Sistem dibangun dengan arsitektur RESTful API menggunakan framework FastAPI dan basis data MySQL, yang mendukung digitalisasi verifikasi berkas secara langsung oleh administrator. Evaluasi performa sistem melalui uji beban multi-skala dari 50 hingga 500 Virtual Users (VUs) menunjukkan backend mampu beroperasi optimal pada rentang 50--300 VUs dengan rata-rata latensi rendah antara 192 ms hingga 271 ms, throughput mencapai 616,96 req/s, serta tingkat kegagalan respon 0,00\%. Namun, titik jenuh tercapai pada beban puncak 500 VUs dengan peningkatan latensi rata-rata menjadi 407 ms dan error rate mencapai 60,25\%. Selain keandalan arsitektur, evaluasi penerimaan sistem diuji menggunakan pendekatan Technology Acceptance Model (TAM) pada variabel persepsi kebermanfaatan dan kemudahan penggunaan dengan tingkat penerimaan sebesar [XX,XX]\%. Platform ini diharapkan dapat mempercepat alur birokrasi layanan serta mempermudah pemetaan potensi sebaran UMKM secara transparan dan terukur.
\end{abstract}

\section{Pendahuluan}
\subsection{Latar Belakang}
Sektor Usaha Mikro, Kecil, dan Menengah (UMKM) merupakan penopang utama stabilitas ekonomi daerah Jawa Barat dengan populasi lebih dari 7,05 juta unit usaha [1], [2]. Perkembangan transparansi data pemerintah daerah melalui portal data terbuka mendorong optimalisasi tata kelola dan pemanfaatan informasi publik secara lebih luas [1], [3]. Namun, penyediaan data terbuka tersebut belum sepenuhnya diimbangi oleh saluran partisipasi yang interaktif serta keterpaduan tindak lanjut layanan administrasi [3], [4]. Publikasi data yang masih disajikan secara tabular statis menyulitkan para pelaku usaha, mitra bisnis, maupun penyalur barang dalam membaca potensi sebaran niaga secara kontekstual [1], [2], [5].

Kondisi tersebut diperberat oleh saluran pengurusan program UMKM yang masih berjalan terpisah-pisah, mulai dari permohonan bantuan sarana modal, registrasi kurasi pelatihan, hingga perizinan legalitas [2], [4]. Ketiadaan pintu layanan terpusat membuat proses pengajuan minim fasilitas pelacakan status (\textit{tracking}) serta rentan terhadap kesalahan input data persyaratan administratif [3], [4]. Pemanfaatan sistem informasi geografis interaktif yang dipadukan dengan layanan perizinan mandiri terbukti efektif mempercepat transparansi rantai layanan sektor publik [5], [7]. Untuk menjawab persoalan ini, dibutuhkan keterpaduan sistem yang menyatukan transparansi data spasial dengan standarisasi alur pengajuan layanan publik dalam satu platform terpusat.

Berdasarkan permasalahan tersebut, penelitian ini mengusulkan SI-UMKM Jabar sebagai platform terintegrasi berbasis web yang memadukan visualisasi peta sebaran kategori usaha berkode warna dan digitalisasi layanan mandiri. Sistem menghubungkan pemohon secara langsung dengan panel verifikasi administrator melalui arsitektur backend FastAPI berkecepatan tinggi, integrasi formulir terstruktur, serta pelacakan status pengajuan secara \textit{real-time}. Untuk memastikan keandalan konkurensi layanan ketika diakses masyarakat secara massal, pengujian performa backend dilakukan secara komprehensif menggunakan simulasi beban bertahap Postman dari skala 50, 100, 200, 300, hingga 500 pengguna simultan (\textit{Virtual Users}). Parameter evaluasi mencakup \textit{throughput} transaksi, rata-rata latensi, respon persentil (P90, P95, P99), persentase \textit{error request}, serta utilisasi perangkat keras (CPU dan RAM).

\section{Literature Review}
Sebagai basis referensi empiris layanan daerah, penelitian ini merujuk pada portal resmi Dinas Koperasi dan Usaha Kecil (DISKUK) Provinsi Jawa Barat [8]. Portal tersebut menyediakan direktori program pembinaan, publikasi agenda UMKM, serta kanal informasi kebijakan pemerintah provinsi. Kendati demikian, penyediaan informasi dan fasilitas layanan publik pada portal eksisting masih bersifat satu arah dan terpisah antarsubdirektorat. Pelaku usaha belum memperoleh akses terpadu untuk memantau status berkas perizinan secara \textit{real-time}, dan visualisasi sebaran pelaku usaha belum terintegrasi secara dinamis ke dalam pemetaan tematik spasial 27 kabupaten/kota.

Melihat keterbatasan tersebut, SI-UMKM Jabar dikembangkan sebagai bentuk eskalasi fungsional dan teknologis dari model layanan DISKUK yang ada:
\begin{enumerate}
    \item \textbf{Single-Window Service}: Mengonsolidasikan alur pengajuan fasilitasi sarana, legalitas, dan kurasi pelatihan ke dalam satu akun terpadu pemohon yang terhubung langsung ke panel verifikasi admin.
    \item \textbf{Transformasi Peta Spasial Dinamis}: Mengonversi data direktori wilayah ke dalam peta interaktif berbasis kode warna sebaran komoditas 27 kabupaten/kota untuk memudahkan analisis potensi ekonomi daerah.
    \item \textbf{Real-Time Tracking}: Menyediakan fitur pelacakan status audit berkas bagi pelaku usaha secara transparan, didukung arsitektur RESTful API performa tinggi berbasis FastAPI serta penyimpanan berkas proposal pada \textit{cloud storage}.
\end{enumerate}

\section{Architecture \& Design System}
Arsitektur SI-UMKM Jabar dirancang dengan mengadopsi prinsip pemisahan tanggung jawab antara antarmuka klien dan \textit{client-server separation} yang terhubung melalui antarmuka pertukaran data standar berbasis RESTful API, seperti ditampilkan pada Fig. 1. Struktur sistem dikelompokkan ke dalam empat lapisan fungsional utama, yaitu \textit{stakeholder layer}, \textit{frontend client layer}, lapisan logika bisnis dan API, serta lapisan penyimpanan data. Lapisan pengguna mengakomodasi tiga entitas utama dengan hak akses terisolasi, yang mencakup masyarakat umum untuk eksplorasi direktori niaga, pelaku UMKM untuk pengajuan layanan mandiri, serta fasilitator dinas sebagai administrator verifikator. Pada lapisan klien, antarmuka dibangun menggunakan arsitektur \textit{Single Page Application} (SPA) berbasis pustaka ReactJS guna memastikan transisi tampilan yang responsif tanpa \textit{full page reload}.

\centering

Komunikasi data antara antarmuka pengguna dan basis data diproses oleh lapisan backend berkinerja tinggi berbasis framework asinkron FastAPI. Lapisan ini mengintegrasikan mekanisme pengamanan rute melalui otentikasi \textit{stateless} JSON Web Token (JWT) berbasis peran, validasi skema data masukan secara ketat menggunakan model Pydantic, pemetaan relasi entitas melalui SQLAlchemy ORM, serta pemrosesan dokumen biner perizinan via Python multipart form parser. Untuk menjaga efisiensi I/O basis data saat melayani lonjakan request, sistem menerapkan strategi pemisahan penyimpanan. Seluruh data terstruktur dan log status pengajuan dikelola di dalam basis data relasional MySQL, sedangkan file fisik berkas legalitas dan proposal usaha dialokasikan secara terpisah pada Supabase Object Storage yang terhubung melalui rujukan URL aman.

Implementasi antarmuka frontend mengadopsi struktur perancangan \textit{design system} berbasis komponen modular guna menjamin konsistensi visual dan kemudahan navigasi pengguna, seperti diilustrasikan pada Fig. 2. Sistem antarmuka ini dibagi ke dalam dua lingkungan kerja utama, yaitu portal layanan mandiri publik dan panel audit verifikasi internal dinas. Portal publik menyediakan antarmuka visualisasi spasial 27 kabupaten/kota di Jawa Barat berbasis kode warna zonasi wilayah dan titik persebaran komoditas usaha secara interaktif, direktori katalog produk, serta modul pengajuan program fasilitasi yang dilengkapi fitur pelacakan status audit berkas secara \textit{real-time}. Sementara itu, panel internal dinas menyediakan tata letak dasbor verifikator yang mencakup tabel manajemen antrean berkas, fitur pratinjau dokumen persyaratan secara langsung, modul validasi persetujuan maupun penolakan bersyarat dengan catatan evaluasi terintegrasi, serta modul ekspor rekapitulasi data layanan untuk kebutuhan pelaporan administratif.
